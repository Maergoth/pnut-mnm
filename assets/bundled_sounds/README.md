# Bundled Fizzle recording

`fizzle.mp3` is the sound file supplied by the user for the Fizzle starter. The copy is
unchanged: 7,457 bytes, SHA-256
`cc1fa5c8b23bd4d227ac7a7c6e890012f80e45e9c2593200f9c6914357738947`.

The app resolves this resource from its source tree or frozen package. Do not replace it
with a personal filesystem path or generate it in the mutable sound cache.
