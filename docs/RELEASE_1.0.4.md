# PNUT M&M 1.0.4

- The Revenge List pop-out now matches the overlay's style, background opacity, text size and move/resize lock.
- Revenge controls stay on their own overlay tab when the list refreshes.
- Saved names appearing in the combat log can show a fading trigger notification, soft flash and quiet tone. Customize these alerts under **Settings > Revenge List**, including duration and the quiet interval before another alert.
- Settings now group overlay, Revenge, combat, clipboard, capture and log options together, with diagnostics at the bottom.
- Revenge List remains off by default and works in either Carebear or Elitist Scumbag Mode. Manual names remain unrestricted; display limits never delete entries or exclude them from alerts.

Download `PNUT-MnM-1.0.4-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates**.
