# PNUT M&M 1.0.0

PNUT 1.0 adds guided setup, Casual Mode, an optional PvP Revenge List, saved history and profiles, and improvements to capture, storage and updates.

- **Casual Mode is on by default.** See your own information and eligible group averages across the app, overlays and exports. Drag the red slider and confirm the teammate promise to use Elitist Scumbag Mode.
- **First-time setup** guides character/mode, Combat chat crop and OCR, then common options: Revenge List, map, auto attack bar and copying finished fights to the clipboard. The local calibration image is visible and cleared when setup closes.
- **Revenge List** is off by default. Save eligible PvP attackers from a 30-second prompt, or add any name manually. Use the main list, overlay tab or pop-out; filter days and entries, newest activity first. Names remain hidden in Casual Mode.
- **Saved history, capture profiles and preference backups** make it easier to return to a session or another character. Help includes a synthetic demo and capture diagnostics.
- **Reliability and performance:** responsive capture stopping, cancellable imports, bounded history, atomic saves, timer matching limits, background map decoding and update recovery. Automatic clipboard copying remains opt-in.
- **Startup executable cleanup** removes verified inactive session copies and retries files that are still in use, preserving the running app and saved data.

Download **PNUT-MnM-1.0.0-windows.zip**, extract it into a writable folder, and keep `_internal` beside **PNUT M&M.exe**. Existing installations can use PNUT's Update option. The companion `.zip.sha256` file records the package checksum.

Windows 10/11 and the English (United States) OCR language pack are required. PNUT continues to capture displayed pixels and process OCR locally.
