# PNUT M&M 1.0.6

- **Show other groups** now applies inside your own fights. Turn it off to hide italic names from every Live and overlay meter tab, including nearby groups' combat.
- Right-click a player and choose **Add pet** to select from the hidden italic names. Assigned pets remain visible with their owner and combine as **Name + Pet**.
- Combat capture and the raw feed remain unchanged, so hiding other groups does not remove data used by triggers or detection.

Download `PNUT-MnM-1.0.6-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates**.
