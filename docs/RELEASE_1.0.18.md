# PNUT M&M 1.0.18

- Ancient Crypt and other large maps load at full resolution, preserving labels when zoomed. Decoder failures no longer delete cached originals.
- Removed the Mez Breaks metric from Session, overlays and exports. Existing saves remain readable, and ordinary mez crowd-control tracking is unchanged.
- Renamed the encounter header to **Group DPS** and clarified **Aggro events** as reported angry-at notices and explicit taunts.
- Recognizes more mana-restoration, dice-roll, trade, Hardcore, flavor and skill-up messages. Mana restoration does not count as HP healing, and outgoing trade money does not count as income.

Installed copies can use **Settings > App updates**. For a portable copy, extract `PNUT-MnM-1.0.18-windows.zip` into a writable folder and run `PNUT M&M.exe` with `_internal` beside it.
