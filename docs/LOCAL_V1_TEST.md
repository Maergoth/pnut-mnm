# Local v1 test candidate

Run `Development/dist/candidates/setup-options-20261010/PNUT M&M/PNUT M&M.exe`, or extract the portable ZIP under that candidate's `releases` folder into a new writable folder and run its executable. Keep `_internal` beside it. This is a Development candidate; the installed `App` copy and published 0.9.1 release are separate. Previous candidates and their captured files are preserved. The currently running first-time preview uses a fresh, separate configuration; its path is recorded in `build/latest-setup-preview.txt`.

1. Setup offers character/mode on step 1, crop and OCR on step 2, then **Common options** on step 3: **Revenge List**, **Display map**, **Auto attack bar**, and **Copy to clipboard after fight**. Finish saves the mode and options together; Back preserves choices and Cancel leaves current preferences alone. Map and bar switches reflect their current state. Capture frame shows a local calibration image even in Casual Mode; closing setup clears it. A successful OCR test allows Continue without a crop confirmation checkbox. Existing saved character/crop profiles skip first-run setup; Help can reopen it. Try Stop, Start, unavailable game recovery and your usual layout.
2. Casual Mode starts on. Check your own values and group averages on Live, Session, overlays, history, clipboard and file exports. Other individuals should remain hidden. Small or unknown groups show self only.
3. Click the flower mode label to open **Morality Adjustment** below Map updates. Clicking the red handle or making a short drag should keep Casual Mode. Drag it most of the way right to request **Elitist Scumbag Mode**. Cancel, Escape and closing the pledge should keep Casual Mode; checking the promise and confirming should enable full details. Return to Casual and check that old details disappear immediately. The slider has a sad emoji; the full-mode top-bar label is on fire (static when reduced animations are enabled).
4. Enable **Revenge List** and save settings. Its identities are available in confirmed Elitist mode. Check the Timers/Triggers panel and overlay Revenge tab, manual Add/Remove with arbitrary names or labels, **Pop out**, and a PvP attack prompt with a right-hand **+**, the 30-second expiry, and one prompt per attacker per session. Ignore named NPCs. Set the history days and entries shown (defaults 30 days / 100 entries; All removes either limit). Confirm newest activity comes first on all three lists and changing limits keeps hidden entries saved. Disable the option and confirm the panel, tab and pop-out disappear.
5. Import a log, cancel another import, browse previous sessions and page through older fights. In full mode, edit a selected archived fight's group/pet attribution and reload that session to verify it was saved. Resume a prior session only while stopped.
6. Save/apply a named capture profile, back up preferences, then restore the backup. Restoring should return to Casual Mode. Try the Help demo and confirm it stays clearly labeled and cannot export fictional data.
7. Try mute, reduced animations, keyboard navigation, your DPI/monitor setup and a longer gameplay session. Record inaccurate totals, unexpected names, capture stalls or growing memory use with the steps that caused them.

Casual Mode protects combat views, OCR results and new PNUT exports. The local setup calibration image is a temporary exception. Existing raw local logs, prior external copies and full-mode exports remain available on disk. The assessment lists the remaining gameplay, clean Windows, accessibility and endurance checks before publication.

These candidate builds record dirty Development provenance and stay separate from release assets. Published packages use a clean committed build and are available through [GitHub Releases](https://github.com/Maergoth/pnut-mnm/releases).
