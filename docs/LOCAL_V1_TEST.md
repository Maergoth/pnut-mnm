# Local v1 test candidate

Run `Development/dist/publish/v1.0.1/PNUT M&M/PNUT M&M.exe`, or extract its portable ZIP from the `releases` folder into a new writable folder and run its executable. Keep `_internal` beside it. Previous candidates and their captured files are preserved. The earlier first-time preview uses a separate configuration recorded in `build/latest-setup-preview.txt`; it predates the Carebear rename and role-based averages.

1. Setup offers character/mode on step 1, crop and OCR on step 2, then **Common options** on step 3: **Revenge List**, **Display map**, **Auto attack bar**, and **Copy to clipboard after fight**. Finish saves the mode and options together; Back preserves choices and Cancel leaves current preferences alone. Map and bar switches reflect their current state. Capture frame shows a local calibration image even in Carebear Mode; closing setup clears it. A successful OCR test allows Continue without a crop confirmation checkbox. Existing saved character/crop profiles skip first-run setup; Help can reopen it. Try Stop, Start, unavailable game recovery and your usual layout.
2. Carebear Mode starts on. Check your own values and group averages on Live, Session, overlays, history, clipboard and file exports. Each damage/DPS average needs three active damage contributors whose damage is at least their healing; each healing/HPS average needs three active healing contributors whose healing is at least their damage. Positive ties count in both; inactive members count in neither. Smaller role cohorts show — and omit that average from exports. Other individuals should remain hidden. Small or unknown groups show self only.
3. Click the flower mode label to open **Morality Adjustment** below Map updates. Clicking the red handle or making a short drag should keep Carebear Mode. Drag it most of the way right to request **Elitist Scumbag Mode**. Cancel, Escape and closing the pledge should keep Carebear Mode; checking the promise and confirming should enable full details. Return to Carebear and check that old details disappear immediately. The slider has a sad emoji; the full-mode top-bar label is on fire (static when reduced animations are enabled).
4. Enable **Revenge List** and save settings. Its identities are available in confirmed Elitist mode. Check the Timers/Triggers panel and overlay Revenge tab, manual Add/Remove with arbitrary names or labels, **Pop out**, and a PvP attack prompt with a right-hand **+**, the 30-second expiry, and one prompt per attacker per session. Ignore named NPCs. Set the history days and entries shown (defaults 30 days / 100 entries; All removes either limit). Confirm newest activity comes first on all three lists and changing limits keeps hidden entries saved. Disable the option and confirm the panel, tab and pop-out disappear.
5. Import a log, cancel another import, browse previous sessions and page through older fights. In full mode, edit a selected archived fight's group/pet attribution and reload that session to verify it was saved. Resume a prior session only while stopped.
6. Save/apply a named capture profile, back up preferences, then restore the backup. Restoring should return to Carebear Mode. Try the Help demo and confirm it stays clearly labeled and cannot export fictional data.
7. Try mute, reduced animations, keyboard navigation, your DPI/monitor setup and a longer gameplay session. Record inaccurate totals, unexpected names, capture stalls or growing memory use with the steps that caused them.
8. Check a personal rebuff timer in Carebear Mode: its static title should remain visible, including after switching modes. Captured names and values should stay hidden. In Damage, 25% of the actual group total should show 25% for you and 75% on the group row, independently of the displayed average.

Carebear Mode protects combat views, OCR results and new PNUT exports. The local setup calibration image is a temporary exception. Existing raw local logs, prior external copies and full-mode exports remain available on disk. The assessment lists the remaining gameplay, clean Windows, accessibility and endurance checks before publication.

These candidate builds record dirty Development provenance and stay separate from release assets. Published packages use a clean committed build and are available through [GitHub Releases](https://github.com/Maergoth/pnut-mnm/releases).
