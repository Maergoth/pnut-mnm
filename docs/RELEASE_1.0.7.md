# PNUT M&M 1.0.7

- The **Revenge pop-out** remembers whether it was open, its position and its size across normal restarts and app updates. Enable **Revenge List** in Settings to use it.
- Removing a player or guild reminder from the pop-out asks for confirmation.
- Each list has **Copy CSV to Clipboard** and **Import CSV from Clipboard** icons. Imports open a preview in that list's Add dialog; choose **Add** to confirm.

Download `PNUT-MnM-1.0.7-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates**.
