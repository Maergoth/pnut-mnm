# PNUT M&M 1.0.24

- Hover settings gears float over each overlay's existing content. They do not reserve a column, add padding or enlarge a compact timer/attack bar. Short bars use a smaller gear; hover visibility, click-through and settings shortcuts still apply.
- NPC respawn timers created through the right-click menu show the same monster icon used on the map, centered inside the radial countdown. The icon follows the timer's normal, warning and expired colors, remains visible after expiration and stays when that timer is restarted. Other timers retain their existing display.
- Overlay gears open the main app at the relevant options and briefly outline the destination; the timer gear highlights its timer list in Triggers. Reduced motion uses a steady brief outline.
- Weapon delay is visible beside the auto-attack toggle in Settings > Overlay. Enter weapon-stat units (36 = 3.6 seconds), or 0 for automatic timing. This immediate preference stays synchronized with the bar's right-click editor and preference backups, without clearing learned swings.
- The Live page and tray now say **End Encounter** for the action that closes the current fight and retains its results.
- Mini stats retain current and maximum weight. Two fresh over-capacity readings start a gray screen-edge pulse, which stops after a valid reading at or below capacity. The **Overburdened warning** option in **Mini stat window** disables it independently of low-health alerts. Red health warnings take priority when both are active; reduced motion keeps the edge glow steady.
- Hover the combat-chat or mini-stat screen read area to reveal its top-left settings gear. It follows the captured game window and opens the relevant highlighted options. The rest of the read area continues passing input to the game.

Windows regression, startup and extracted portable-package checks gate publication. Installed copies update through **Settings > App updates** after this release is published.
