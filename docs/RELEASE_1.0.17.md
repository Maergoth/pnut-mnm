# PNUT M&M 1.0.17

The Session footer uses **Hourly:** with compact kill, item, coin and XP values, removing the repeated `/h` suffixes. Rate calculations are unchanged.

Installed copies can use **Settings > App updates**. For a portable copy, extract `PNUT-MnM-1.0.17-windows.zip` into a writable folder and run `PNUT M&M.exe` with `_internal` beside it.
