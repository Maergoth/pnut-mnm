# PNUT M&M 1.0.3

- Downloaded updates survive quitting. Restart immediately with **Restart to update**, or quit and reopen PNUT to install. Closing to the tray keeps the app running.
- Saved updates are verified again before installation. The installer still preserves your settings, triggers, logs, maps, sessions and Revenge List, and restores the previous app if the replacement fails to start.
- Scrolling over settings no longer changes values accidentally, including focused fields. This also covers trigger settings, setup, profiles, crop controls and respawn duration. Opened dropdowns can still scroll their choices.

Download `PNUT-MnM-1.0.3-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates**.

The quit-and-reopen update behavior starts with this version. To install 1.0.3 from an older build, use its **Restart to update** button.
