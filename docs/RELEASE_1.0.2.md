# PNUT M&M 1.0.2

Carebear Mode now focuses on preventing direct comparisons with individual group members. Your own performance and eligible group averages remain visible; other members' individual results remain hidden in performance views and exports.

- Trigger names, patterns, matches, regex values, timer labels, custom speech, sounds, editing and sharing work normally in Carebear Mode.
- The Feed keeps original captured lines across mode changes, including when copied. Capture calibration, OCR tests, diagnostics, preference backups and the enabled Revenge List are also available in either mode.
- Your meter row offers **Assign a pet to me…** in Carebear Mode so you can fix your own pet attribution without opening individual groupmate results.
- Maps follow known-zone `/who` summaries as well as zone-entry messages. Current zone metadata is synchronized across maps, sessions and active fights, including restored captures and compact names such as FallenPass.

New installs still start in Carebear Mode. Existing settings and trigger definitions are preserved.

Download `PNUT-MnM-1.0.2-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates** to install 1.0.2.
