# PNUT M&M 1.0.29

- XP tracking excludes the beveled frame from scaled XP bars. Both fills use
  the same interior width, so the existing consistency check accepts valid
  readings and XP/hour can finish its normal observation window.
- Each new daily leaderboard submission replaces that anonymous identity's
  previous entry. Existing daily duplicates display as one entry using the
  latest accepted update. The daily submission limit remains unchanged.
- Identity recovery retains older published personal bests. Updates from other
  identities and delayed acknowledgements cannot replace your latest entry.
