# PNUT M&M 1.0.26

- Right-click a displayed map image and choose **Add label…** to save a name,
  optional notes and a pin, star, camp, treasure, danger or merchant icon. The icon
  stays visible; hover for the name and notes, or right-click to edit or delete it.
- Labels belong to the specific map image file, independently of zone names.
  Alternate drawings and floors keep separate labels. Positions follow the image
  through pan, zoom, resizing and resolution changes. Saved labels survive restarts
  and are shared by the map overlay and the main **Zones** browser.
- Leaderboard names now use larger bold gold text with one word on each of the
  entry's three rows. The default sort is **Stat Total**, highest first; entries
  with unavailable totals remain last.
- **Snare the Dead** and **Fear the Dead** are recognized as control abilities.
  The observed **is overcome with fear** result earns landed fear/utility credit.
  Resists, fizzles, expiration notices and effects without a matching cast do not
  earn successful utility credit.

Windows regression, executable startup/provenance and extracted portable-package
checks gate publication. This update uses the existing leaderboard upload service.
