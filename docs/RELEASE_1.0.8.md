# PNUT M&M 1.0.8

- Each **Revenge pop-out** list now has a **+** button and a clipboard copy icon in its compact header.
- **+** opens that list's Add dialog. Enter names manually or choose **CSV from clipboard**, review the selected list's entries, then choose **Add** to save.
- **Copy CSV to Clipboard** copies the selected list as one comma-separated row of names: `NAME,NAME,NAME`. Paste the same format into its Add dialog; older `Type,Name` CSV imports still work.

Download `PNUT-MnM-1.0.8-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates**.
