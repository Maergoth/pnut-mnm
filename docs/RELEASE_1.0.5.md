# PNUT M&M 1.0.5

- The Revenge List pop-out now shows the same dotted resize grip as the normal overlay. Unlock the overlay and drag the dots in the bottom-right corner to resize it.
- Guilds and Players have separate lists side by side, each with its own Add and CSV Export. The pop-out uses a compact hover header, like the map.
- Resizing the window taller makes room for more entries instead of leaving the list at a fixed height.
- **Add Guild(s)** and **Add Player(s)** offer **From Clipboard** to import several names from CSV. Import merges into the selected list without replacing saved activity dates; Guild entries remain reminders.
- **What's New!** highlights new features once after each update, with a shortcut to their settings.
- Timer sharing uses compact codes copied to the clipboard or saved as a file. Import has one data box: paste text or open a file, then choose Import. Existing JSON is accepted too; every timer setting is preserved.

Download `PNUT-MnM-1.0.5-windows.zip`, extract it into a writable folder and run `PNUT M&M.exe` with `_internal` beside it. Installed copies can use **Settings > App updates**.
